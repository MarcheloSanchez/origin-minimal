# 🗃️My PKM Glossary
## Slovníček klíčových pojmů

|                                         |                                                                                                                                                      |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pojem                                   | Definice                                                                                                                                             |
| **Atomic Note (Dot)**                   | Atomická poznámka; základní stavební kámen znalostí, který se zaměřuje na jeden konkrétní koncept, nápad nebo informaci.                             |
| **Archive (Archiv)**                    | Cílové umístění (složka `06-Archive`) pro dokončené, neaktivní nebo zrušené položky, které již nevyžadují aktivní pozornost, ale mají být zachovány. |
| **Capture (Zachycení)**                 | První fáze životního cyklu znalostí, zaměřená na rychlý a bezproblémový sběr informací a nápadů do složky `+Inbox`.                                  |
| **Dataview**                            | Plugin pro Obsidian, který umožňuje vytvářet dynamické seznamy, tabulky a reporty dotazováním metadat a obsahu poznámek.                             |
| **DryRun**                              | Argument pro YAML Orchestrator, který umožňuje zobrazit náhled změn v samostatném souboru, aniž by se provedly úpravy v původních poznámkách.        |
| **Effort (Projekt)**                    | Typ poznámky představující aktivní projekt nebo dlouhodobou iniciativu. Sleduje se u něj stav, priorita a další akce.                                |
| **Evergreen**                           | Stádium zralosti poznámky, které představuje stabilní, zralou a často odkazovanou znalost.                                                           |
| **GTD (Getting Things Done)**           | Metodologie pro řízení úkolů a produktivitu, jejíž principy (např. inbox, další akce) jsou integrovány do systému.                                   |
| **Hotkey (Klávesová zkratka)**          | Kombinace kláves přiřazená k určité akci pro zrychlení a zefektivnění práce v aplikaci Obsidian.                                                     |
| **Kanban**                              | Plugin a metoda pro vizuální řízení pracovních postupů, používaný pro sledování stavu projektů a iniciativ na úrovni „Roadmap“.                      |
| **Lint (režim)**                        | Režim nástroje YAML Orchestrator, který pouze skenuje metadata, hledá problémy a generuje zprávu bez provádění změn.                                 |
| **Metadata**                            | Strukturovaná data na začátku poznámky (v sekci YAML), která popisují její vlastnosti, jako je typ, stav, datum vytvoření atd.                       |
| **MOC (Map of Content)**                | Mapa obsahu; poznámka, která slouží jako rozcestník pro určité téma a obsahuje kurátorované odkazy na související poznámky.                          |
| **Normalize (režim)**                   | Režim nástroje YAML Orchestrator, který kompletně přepisuje YAML metadata za účelem opravy a sjednocení hodnot.                                      |
| **PKM (Personal Knowledge Management)** | Správa osobních znalostí; systém a praxe pro zachycení, organizaci a využití osobních znalostí a informací.                                          |
| **QuickAdd**                            | Plugin pro Obsidian, který umožňuje rychlé vytváření poznámek a úkolů pomocí předdefinovaných šablon a maker.                                        |
| **Reorder (režim)**                     | Režim nástroje YAML Orchestrator, který bezpečně mění pořadí klíčů v YAML metadatech podle definované šablony.                                       |
| **Review (Revize)**                     | Fáze životního cyklu znalostí zaměřená na pravidelnou údržbu, kontrolu a aktualizaci systému v denních, týdenních, měsíčních a čtvrtletních cyklech. |
| **Seed (Zárodek)**                      | Počáteční stádium zralosti poznámky; syrový, nezpracovaný záznam z inboxu, který vyžaduje další rozpracování.                                        |
| **Source (Zdroj)**                      | Typ poznámky pro referenční materiály, jako jsou knihy, články, videa nebo zápisy ze schůzek.                                                        |
| **Tag (Štítek)**                        | Klíčové slovo (často s prefixem `#`), které popisuje atributy, kontext nebo stav poznámky a umožňuje její vícerozměrnou organizaci.                  |
| **Templater**                           | Plugin pro Obsidian, který umožňuje automatizovat tvorbu poznámek pomocí pokročilých šablon, které mohou obsahovat proměnné a funkce.                |
| **WIP (Work in Progress)**              | Zkratka pro „Práce v procesu“, alternativa ke stavu `🔄active`.                                                                                      |
| **Workflow (Pracovní postup)**          | Definovaná posloupnost kroků od zachycení informace až po její archivaci, která zajišťuje systematické zpracování znalostí.                          |
| **YAML**                                | Jazyk pro serializaci dat, který se v Obsidianu používá pro definování metadat (front-matter) na začátku Markdown souborů.                           |
| **YAML Orchestrator**                   | Uživatelský skript pro Templater, který hromadně zpracovává YAML metadata v poznámkách za účelem jejich sjednocení a údržby.                         |
