## 🆓 Volné zkratky

> [!warning] Ctrl+Alt+{F,G,B,N,Q,W,V} = AltGr znaky na CZ layoutu — nikdy nepřiřazovat.

**Ctrl+[Key] - Dostupné pozice**

```
Ctrl+D, Ctrl+G, Ctrl+H, Ctrl+I, Ctrl+J, Ctrl+L, 
Ctrl+R, Ctrl+T, Ctrl+U, Ctrl+W
```

**Doporučené rozdělení Ctrl:**
- Ctrl+D - Duplicate line
- Ctrl+G - Go to line
- Ctrl+H - Replace
- Ctrl+J - Join lines
- Ctrl+L - Select line
- Ctrl+R - Refresh/Reload
- Ctrl+T - New tab
- Ctrl+U - Underline
- Ctrl+W - Close tab

**Alt+[Key] - Dostupné pozice**

```
Alt+A, Alt+B, Alt+H, Alt+I, Alt+J, Alt+K, Alt+L, 
Alt+M, Alt+O, Alt+P, Alt+S, Alt+U, Alt+V, Alt+X, 
Alt+Y, Alt+Z
```

**Doporučené rozdělení Alt:**
- Alt+A - Archive quick
- Alt+B - Bookmarks
- Alt+H - Help/Hints
- Alt+I - Info panel
- Alt+J - Jump to note
- Alt+K - Kanban view
- Alt+L - Link suggestions
- Alt+M - Metadata panel
- Alt+O - Open recent
- Alt+P - Properties
- Alt+S - Statistics
- Alt+U - Update modified
- Alt+V - Vault switcher
- Alt+X - Extensions
- Alt+Y - Yesterday's notes
- Alt+Z - Zen mode

**Ctrl+Shift+[Key] - Dostupné pozice**

```
Ctrl+Shift+A, Ctrl+Shift+B, Ctrl+Shift+C, Ctrl+Shift+E,
Ctrl+Shift+G, Ctrl+Shift+H, Ctrl+Shift+J, Ctrl+Shift+K,
Ctrl+Shift+L, Ctrl+Shift+P, Ctrl+Shift+Q,
Ctrl+Shift+R, Ctrl+Shift+S, Ctrl+Shift+T, Ctrl+Shift+U,
Ctrl+Shift+V, Ctrl+Shift+X, Ctrl+Shift+Y, Ctrl+Shift+Z
```
