## Ideas to Try

- Structured output comparison: same task with JSON constraint vs free-form — which is more useful?
- Temperature sweep: run same creative prompt at 0.3 / 0.7 / 1.0, compare quality
- Prompt compression: take a verbose mega-prompt and reduce to minimal version, compare output
