# 📋 Tools Folder Contract

**What**: Documentation and assessment of tools you actively use—software, hardware, methodologies, systems. Your personal verdict, configuration, and application patterns. One tool per note.

**When**: Created when adopting a tool you use regularly. Updated as you deepen mastery or adjust configuration.

**Where**: `02-Knowledge/Tools/` — one `.md` file per tool, organized by category (Software, Hardware, Methodologies) as needed.

**Lifecycle**: Create via QuickAdd Tool choice (→ `Templates/Static/tool.md`). Link from efforts and workflows that use it. Archive when you stop using a tool.

---

## ✅ What Belongs Here

- Software applications you actively use and have configured
- Hardware tools and equipment you own and use
- Methodologies and frameworks you've adopted and adapted
- Systems and workflows you've built and use regularly
- Integrations and custom configurations
- Your personal assessment and recommendations

## ❌ What Doesn't Belong Here

- **Third-party how-to guides** → [[Guides]] (external documentation)
- **Tools you've stopped using** → [[06-Archive]] (archived tools)
- **General tool reviews** → [[Atomics]] (concepts, not your personal tools)
- **General tutorials** → [[04-Sources]] (external learning material)

## 📖 Real Tool Examples

> [!example]+ **Software: Obsidian (Knowledge Management)**
> - **Purpose**: PKM system for vault management
> - **Key Plugins**: Templater, QuickAdd, Dataview, BRAT
> - **Config**: Vault structure, custom CSS, daily notes template
> - **Daily Use**: Note capture, linking, queries, automation
> - **Verdict**: 🟢 Essential tool, core to workflow
> - **Related**: `[[Effort: Vault Optimization]]`, `[[AIOS System]]`

> [!example]+ **Methodology: Zettelkasten (Atomic Note-Taking)**
> - **Concept**: Each note captures one idea, linked by topic and relationship
> - **My Application**: Atomic notes in 02-Knowledge, MOCs for navigation
> - **Benefits**: Reduces duplication, forces clarity, enables discovery
> - **Integration**: Foundation of entire vault structure
> - **Resources**: `[[Source: How to Take Smart Notes — Ahrens]]`

> [!example]+ **Hardware: Prusa i3 MK3S+ (3D Printer)**
> - **Use**: Prototyping, hobby projects, learning manufacturing
> - **Key Specs**: FDM, 250×210mm build area, heated bed, filament sensor
> - **Materials**: PLA, PETG, TPU (experimentation focus)
> - **Maintenance**: Nozzle care, calibration, regular cleaning
> - **Projects**: Home organizers, replacement parts, hobby creations
