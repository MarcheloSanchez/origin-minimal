# Lessons — corrections & rejection reasons

Append-only between quarterly reviews. Every rejected proposal and every human
correction lands here as one dated line with its fix-class and a candidate rule.
At the quarterly review, entries are distilled into `AIOS/rules/ai-rules.md`
(or discarded) and this file is pruned. Provenance rule applies: date, source,
fix-class on every line — speculation is never stored as fact.

Format: `- **YYYY-MM-DD** · <fix-class> · <rejection|correction> — "<reason>". → candidate rule: <one line or "none">`
