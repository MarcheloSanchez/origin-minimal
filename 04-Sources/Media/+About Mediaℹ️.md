# 📋 Media Folder Contract

**What**: Multimedia sources—videos, podcasts, documentaries, talks, webinars. Audiovisual content with processed notes and extracted insights.

**When**: Viewed/listened with real-time notes. Processed within week for key insights.

**Where**: `04-Sources/Media/` — one `.md` file per media item.

**Lifecycle**: Create when capturing. Extract key insights and link to knowledge. Archive if obsolete.

---

## ✅ What Belongs Here

- Videos, documentaries, video courses
- Podcasts, audio content (with notes)
- Talks, presentations, webinars
- Films and visual learning content

## ❌ What Doesn't Belong Here

- **Text articles** → [[Articles]]
- **Structured video courses** → [[Courses]]
- **Your own videos** → [[07-Prompts]]
